this from `images.unsplash.com`, and a third-party request on every page load
would undercut the claim that nothing about a visit leaves the device.

## Note on the earlier hero

The first version of this redesign shipped a different photo (an autumn park path
by Victoria Prymak, https://unsplash.com/photos/gUeWxej5wzE). That was a fallback:
the design file named in the task credited only that one photo, so this one could
not be attributed and, under the task's rule, could not be shipped. The credit for
this photo turned out to be in a second design file in the same archive,
`MR Landing.dc.html`, which is the frame the product owner actually wanted. The
park path is no longer used.
